# Transitly asset and attribution notes

Reviewed 2026-11-22.

- The map uses OpenStreetMap tiles and displays the required OpenStreetMap attribution in the map controls. Tile service terms and usage policy should be followed.
- The Transitly favicon is a project-generated asset (`public/favicon.png`); no stock-photo license is applicable.
- Main Transitly source assets reviewed contain no bundled stock photography. SecondLook displays images selected by the user, which are transient uploads for the requested analysis and are not project stock assets.
- Icons in the interface are inline SVG, CSS shapes, or the installed Lucide icon package. Keep the relevant package license with dependency updates.

This file records the repository audit; it does not replace proof of ownership or licenses for assets added later.
